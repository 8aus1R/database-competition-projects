## RMDB 代码怎么阅读

[提交项目代码](./提交项目代码/)中有 RMDB-test_rmdb、db123-2024-SortMerge、db123-833 和 db123-all_code (4) 四个目录。我保留了原有目录名和各自的 README、许可证及项目文档；它们是不同的代码副本，不建议当成一个工程一起编译，也不在这里把某个目录标为“最终版”。

每个代码目录的 src 下都包含 storage、index、analyze、optimizer、execution、transaction 等模块。如果想顺着一条 SQL 看数据库如何工作，可以先看 [SQL 语句执行流程图](./数据库-结构图/sql语句执行流程图.drawio)，再结合解析、优化与执行模块阅读源码；如果想先理解底层，可以从存储管理和索引笔记开始。

## 环境与运行

RMDB 原有项目文档以 Linux 环境为主，代码使用 C++17 和 CMake；其 README 列出了 GCC、Flex、Bison、Readline 等依赖。实际构建和测试时，请进入选定的代码目录，先阅读该目录的 README、RMDB使用文档.pdf 和 RMDB环境配置文档.pdf。仓库没有提供跨四个代码目录的统一构建或测试入口，也没有在这里声明所有版本都通过了同一组测试。
